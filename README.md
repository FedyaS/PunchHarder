# PunchHarder

## Frontend

```
cd frontend
npm install
npm run dev
```

## Backend

### Create venv

Mac/Linux:
```
python3 -m venv backend/venv
```

Windows:
```
python -m venv backend\venv
```

### Activate venv

Mac/Linux:
```
source backend/venv/bin/activate
```

Windows:
```
backend\venv\Scripts\activate
```

### Install & run

```
cd backend
pip install -r requirements.txt
python app.py
```
